イントロドン

テーマを選ぶだけで遊べる、オンライン早押しクイズ。
サーバー不要・APIキー不要・部屋コードだけで友達とつながります。

※ 全員が同じ曲を各自の端末で同時再生します。早押しは「自分の端末で曲が鳴り始めてからの経過ミリ秒」で判定するので、通信の速い/遅いによる有利不利は出ません。

部屋を作る

料金の目安は30曲生成1回あたりです。採点用のAI判定は1問あたり0.1円未満。
お金をかけたくない場合は「🔎 曲名リストから検索」タブを使ってください。APIキーなしで同じことができます。
選ぶと下の欄にリストが入ります。曲を足したり消したりして調整できます。
3つ目以降の項目は採点用の別表記になります（英題・ひらがな表記など）。入れておくと自動採点の精度が上がります。
上のリストに名前をつけて保存すると、次回からドロップダウンで選べます（この端末に保存）。
📤 マイテーマの書き出し / 読み込み（友達と共有する）
「書き出す」でマイテーマ全部がこの欄に出ます。そのままチャットに貼って友達に送れます。
受け取った側は同じ欄に貼って「読み込む」。.txt で受け取ったなら「📂 ファイル」から直接開けます。
内蔵テーマ以外で遊びたい（無料のチャットAIに作らせる）
無料のチャットAI（claude.ai など）にプロンプトを貼ると、そのまま上の欄に貼れる形式で返ってきます。
形式: URL または動画ID , 曲名 , アーティスト , 開始秒
・曲名にカンマが入る場合は区切りを | にしてください
・開始秒は 45 / 1:20 / 1m20s のどれでもOK。URL の ?t= も自動で読みます
🔑 APIキーの設定（任意・この端末に保存されます）
console.anthropic.com で発行。 未入力でも遊べます（選曲は他タブ、微妙な回答はホストが手動判定）。
Google Cloud で「YouTube Data API v3」を有効化してキーを発行（課金設定は不要）。1日10,000ユニットまで無料で、1曲の検索に100ユニット使います。
未入力でも公開ミラー経由で検索しますが、混雑時は失敗しやすくなります。
