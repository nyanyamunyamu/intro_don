# イントロドン オンライン — 使い方

`introdon.html` 1ファイルだけで動く、友達とオンラインで遊べるイントロドン（早押し曲当てクイズ）です。
サーバーもアカウントも不要。全員が同じ曲を各自の端末で同時再生し、**「自分の端末で音が鳴り始めてからの経過ミリ秒」**で早押しを判定するので、回線の速い遅いによる有利不利が出ません。

---

## 1. 友達に配る

**参加者全員が同じ `introdon.html` を開く**必要があります。方法は3つ。

### A. GitHub Pages に置く（確実・無料・おすすめ）

一度やれば、以降はURLを送るだけで済みます。

1. GitHub でリポジトリを新規作成（Public）
2. `introdon.html` を `index.html` という名前でアップロード
3. リポジトリの Settings → Pages → Source を `main` ブランチの `/ (root)` にして Save
4. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` が使えるようになる
5. そのURLを友達に送る

HTTPS で配信されるので、マイク権限・クリップボード・WebRTC すべてが確実に動きます。

### B. ファイルをそのまま送る

`introdon.html` を LINE / Discord / メールで送り、各自がダウンロードしてダブルクリックで開きます。

セットアップ不要で最速ですが、`file://` で開くと YouTube の埋め込みが動かない環境があります。
**まず各自がトップ画面の「🔧 動作チェック」を押してください。**3つとも ✅ なら問題なく遊べます。
どれかが ❌ なら方法 A に切り替えてください。

### C. 自分のPCでローカルサーバーを立てる（動作確認・一人でのテスト用）

```bash
python -m http.server 8000
```

`http://localhost:8000/introdon.html` を開きます。自分の端末でしか開けないので、友達と遊ぶ用途には使えません。

---

## 2. 遊び方

### ホスト（出題する人）

> **本番前におすすめ**: ホストだけ **YouTube Data API キー**（無料・課金設定不要、下の5章）を取っておいてください。
> キー無しでも動きますが、公開ミラー経由になるため、日によっては半分以上の曲が見つからないことがあります。
> リストは事前に作って「⭐ マイテーマに保存」しておくと、当日は選ぶだけで始められます。

1. 「🎧 部屋を作る」→ 名前を入力
2. **「🎁 テーマから選ぶ」タブ**でテーマを選び「読み込む」
3. 「YouTubeを検索して動画に紐付ける」（20曲で30秒ほど）
4. 設定を調整して「部屋を開く」
5. 「🔊 準備OK！」→ 表示された**部屋コード4文字**を友達に伝える
6. 全員そろったら「▶ ゲーム開始」

ホストも早押しに参加できます。「ホストも参加する」を ON にしておけば、ホスト画面にも答えが表示されません。

### 参加者

1. 「🙋 部屋に入る」→ 名前と部屋コード4文字を入力
2. 「🔊 準備OK！」を押す（ブラウザの制限で、一度タップしないと音が出ません）
3. 曲が流れたら「ドン！」を押す（スペースキー / Enterキーでも押せます）
4. 最速だった人が曲名を入力して回答

### ⚠ ゲーム中はタブを前面にしておく

タブを裏に回すとブラウザが YouTube の再生を止めます。戻ってきたときは「▶ タップして再生」を押せば復帰できますが、その問題は出遅れます。Discord などで通話しながら遊ぶ場合は、ブラウザを別ウィンドウにして並べておくのがおすすめです。

---

## スマホで遊ぶ

PCと同じURLをスマホのブラウザで開くだけです。参加者はスマホ、ホストはPC、という混在もできます。

### スマホの人がやること

1. **マナーモードを解除して、音量を上げてから**「🔊 準備OK！」をタップ
   タップすると一瞬だけ音が鳴ります。これは「この端末で音を出す権利」をブラウザから得るための処理で、
   ここで音が聞こえなければ本番でも聞こえません。**音が鳴らなかったら音量とマナーモードを確認して、
   ブラウザを再読み込みしてやり直してください。**
2. 早押しは画面下の大きな「ドン！」ボタン。指を置いた瞬間に反応します（離すのを待ちません）
3. 回答はキーボードで入力 → 「回答」

### スマホでの注意

- **ホーム画面に戻ったり他のアプリに切り替えると音が止まります。** ゲーム中はブラウザを開いたままにしてください。戻ったときは「▶ タップして再生」で復帰できます
- 通話しながら遊ぶ場合、スマホ1台で Discord とブラウザを行き来するのは無理があります。**通話は別の端末（PCなど）でするのがおすすめ**です
- ゲーム中は画面が自動で消えないようにしています（対応ブラウザのみ）。それでも消える場合は、端末の自動ロック時間を延ばしてください
- ホストをスマホでやることもできますが、リスト作成や判定操作があるのでPC推奨です

### iPhone / iPad について

iOS は「ユーザーが直接タップして再生した要素」しか、以後プログラムから鳴らせません。
そのため「🔊 準備OK！」のタップ時に、あらかじめ用意しておいたプレイヤーをその場で再生して権利を得る作りにしています。

この仕組みは iOS 実機では未検証です。もし毎問「▶ タップして再生」が出るようなら、
その端末ではタップしてから曲が始まるぶん出遅れます。その場合は Android か PC で参加してもらってください。

## 3. 出題リストを追加する

内蔵テーマは10種類・226曲です。自分のリストを足す方法は3通りあります。

### 方法1: その場で作って保存する（いちばん手軽）

1. 「🎁 テーマから選ぶ」タブの**曲名リスト欄**に、1行1曲で入力

   ```
   夜に駆ける, YOASOBI, よるにかける
   Lemon, 米津玄師, レモン
   Bohemian Rhapsody, Queen, ボヘミアンラプソディ
   ```

   - 1つ目 = **曲名**、2つ目 = **アーティスト**、**3つ目以降 = 採点用の別表記**
   - 別表記は自動採点の精度に直結します。英語の曲名には**必ずカタカナ読み**を入れてください
     （`ボヘミアンラプソディ` と答えても正解になります）
   - 曲名にカンマが入る場合は、その行だけ区切りを `|` にしてください
   - 先頭が `#` の行はコメントとして無視されます

2. 下の欄にテーマ名を入れて「⭐ マイテーマに保存」
3. 以降はドロップダウンの「マイテーマ」から選べます

保存先はそのブラウザの localStorage です。**同じ端末の同じブラウザでのみ残ります。**
既存のテーマ名で保存すると上書き更新になります。削除はドロップダウンで選んで 🗑 ボタン。

### 方法2: 友達とテキストで共有する

「📤 マイテーマの書き出し / 読み込み」を開きます。

- **送る側**: 「⬇ 書き出す」→ 出てきたテキストをコピーしてチャットに貼る
- **受け取る側**: 同じ欄に貼って「⬆ 読み込む」

書き出されるテキストはこの形式です。手で書いても構いません。

```
## うちのカラオケ定番
夜に駆ける, YOASOBI, よるにかける
Lemon, 米津玄師, レモン

## 部活の思い出
負けないで, ZARD, まけないで
栄光の架橋, ゆず
```

`## テーマ名` で区切って、複数テーマを一度にやり取りできます。
このテキストを `themes.txt` として保存して送れば、受け取った側は「📂 ファイル」から直接開けます。

### 方法3: HTMLに焼き込む（配る全員に最初から入れたい場合）

`introdon.html` をテキストエディタで開き、`const PRESETS = {` を検索します（1576行目あたり）。
既存のテーマと同じ書式で追記してください。

```javascript
const PRESETS = {
  "マイテーマ名": [
    ["曲名","アーティスト","別表記1","別表記2"],
    ["夜に駆ける","YOASOBI","よるにかける"],
    ["Lemon","米津玄師","レモン"]
  ],
  "J-POP 2020年代": [
    ...
```

注意点:

- 各行は `["曲名","アーティスト", ...]` の形。**ダブルクォートは半角**、行末はカンマ
- 最後の曲の行にはカンマを付けない
- テーマ名にダブルクォートを含めない
- 編集後にブラウザで開き、ドロップダウンに出てくれば成功。出てこない場合は書式ミスです（F12 の Console にエラーが出ます）

内蔵テーマを消したい場合は、そのテーマのブロックごと削除してください。

### リストをAIに作らせる

「内蔵テーマ以外で遊びたい」を開き、テーマを入力して「📋 プロンプトをコピー」または「↗ claude.ai を開く」。
無料のチャットAIに投げると、そのまま貼り付けられる形式で返ってきます。

## 4. 設定項目

| 項目 | 説明 |
|---|---|
| 出題数 | リストからランダムに何問出すか。空欄なら全部 |
| 1問の制限時間 | 誰も押さなかった場合に答えを表示するまでの秒数 |
| 回答の入力時間 | 早押し後、曲名を入力する制限時間。超えると不正解 |
| お手つき | 誤答時に解答権を失うだけか、-1点もするか |
| 再生開始位置 | 「曲のはじめ」= 通常のイントロドン / 「ランダム」= 曲の途中から流すサビ当て風 |
| 自動採点 | 表記ゆれを自動照合。微妙なものだけAI判定（APIキーがある場合） |
| ホストも参加する | ホスト画面に答えを表示しない |

## 5. APIキーについて（すべて任意）

キーが1つも無くても遊べます。

### YouTube Data API キー（無料・推奨）

曲名から動画を探す精度と安定性が上がります。課金設定は不要です。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「YouTube Data API v3」を有効化
3. 「認証情報」→「APIキーを作成」
4. アプリの 🔑 欄に貼る

1日10,000ユニットまで無料。1曲の検索で100ユニット使うので、**30曲のリストを1日3回**作れる計算です。
一度見つけた動画IDはブラウザに保存されるので、同じ曲の再検索は消費しません。

キーが無い場合は公開ミラー経由で検索します。動作確認では20曲中20曲成功したこともあれば、同じミラーで5曲中1曲しか見つからないこともありました（特に日本語の曲名で不安定）。
候補ミラーは8件登録していますが、大半は外部サイトからのアクセスを許可していないため、実質1〜2件に頼っています。
**友達と約束して遊ぶなら、キーを取っておくことを強くおすすめします。**

### Anthropic APIキー（有料）

「🤖 テーマからAIが選曲」タブと、微妙な回答のAI判定に使います。
30曲の生成1回で15円ほど（Claude Opus 5 の場合。Haiku 4.5 を選べば3円ほど）。

キーはあなたのブラウザの localStorage に保存され、Anthropic 以外には送信されません。
共用PCで使う場合は「この端末のブラウザに保存する」のチェックを外してください。

## 6. うまくいかないとき

まずトップ画面の「🔧 動作チェック」を押してください。

| 症状 | 対処 |
|---|---|
| ❌ P2P接続 | 社内/学内Wi-Fiが WebRTC を遮断している可能性があります。モバイル回線やテザリングで試してください |
| ❌ YouTube再生 | 広告ブロッカーなどの拡張機能を切る。別のブラウザで試す |
| ⚠ 曲の検索が使えない | 公開ミラーが落ちています。ホストだけ YouTube Data API キーを設定してください。参加者には不要です |
| 部屋コードが見つからない | ホストがブラウザを閉じている / 別のコードを見ている。ホストは部屋を開いたままにしてください |
| 音が出ない | 「🔊 準備OK！」を押したか確認。画面下の音量スライダーも確認。スマホはマナーモード解除を |
| スマホで毎問「▶ タップして再生」が出る | 音声の許可が取れていません。ブラウザを再読み込みし、音量を上げた状態で「🔊 準備OK！」を押し直してください |
| スマホの画面が消えてしまう | 端末側の自動ロック時間を延ばしてください |
| 曲が流れない・途中で止まる | タブが裏に回っていませんか。前面に戻して「▶ タップして再生」 |
| 生成した曲が何曲か除外される | その動画が埋め込み再生を禁止しています。仕様上ふつうに起きます（20曲中1〜2曲程度） |
| 途中で切断された | 同じ名前で入り直せばスコアを引き継いで復帰できます |

### 既知の制約

- ホストがブラウザを閉じるとゲームは終了します（ホストが通信のハブになっているため）
- 埋め込み再生が禁止されている動画は自動的に除外されます
- 曲名の自動取得はしていません。リストの曲名がそのまま正解として使われます

---

## 7. 動作環境

PC・スマホの Chrome / Edge / Safari で動きます。PCとスマホの混在プレイもできます。
検証は Chromium 系ブラウザの PC 表示と 375×812 のモバイル表示で行いました（iOS 実機は未検証）。
外部依存は PeerJS（P2P通信）と YouTube IFrame API のみで、どちらも CDN から読み込むためインターネット接続が必要です。
